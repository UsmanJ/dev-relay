# DevRelay v0.1.0-alpha.1

First public **alpha** of DevRelay, a local-first, multi-agent software development orchestrator. A product-manager agent, a developer agent and a reviewer agent pass work between each other on your machine. Each role uses an AI coding CLI you already have and are signed in to, and you approve every important step.

> DevRelay is an independent open-source project. It is not an official OpenAI or Anthropic product.

## Highlights

- **PM → developer → reviewer loop:** a structured, schema-validated spec, then implementation in an isolated git worktree on a new branch, then review against the acceptance criteria. The revision loop is bounded (default 2 rounds).
- **Evidence over claims:** DevRelay captures the diff and runs your test command itself. The reviewer is told that the developer's report is unverified.
- **Human gates:** spec approval, per-task authorisation before any code is changed, and a final decision that is always yours. **DevRelay never merges, pushes or deploys.**
- **Bring your own tools:** adapters for the OpenAI Codex CLI (PM/reviewer) and Claude Code (developer, or any role), plus an offline mock provider. DevRelay never handles your credentials.
- **Local dashboard and CLI:** projects, backlog, spec editor, agent timeline, diff and test evidence, pause/resume/retry/cancel, and per-project context and decisions.

## Defaults that matter

- **Developer = manual Claude Code handoff.** Automated `claude -p` execution is opt-in through a one-time acknowledgement. Before enabling it, read [docs/PROVIDERS.md](../PROVIDERS.md). The acknowledgement does not override any provider's terms.
- **No paid API access.** API-key variables are stripped from child processes, and metered adapters are disabled.
- **Localhost only, no telemetry.**

## Try it (5 minutes, no AI account needed)

```powershell
git clone https://github.com/UsmanJ/dev-relay.git
cd dev-relay
npm install
npm run demo            # offline mock cycle
npm run build; npm start   # http://127.0.0.1:3210
```

Then connect your own Codex / Claude Code installations: see the [README](../../README.md#5-minute-quickstart-windows-powershell).

## Platform support

- **Windows 11:** tested hands-on, including real Codex and Claude Code runs.
- **Linux and macOS:** the offline test suite, build and mock demo pass in CI. Real provider runs have not been tested on them yet.
- **Node.js:** 22 or 24.

## Known limitations

- Alpha quality. Real-provider runs were verified on one Windows machine, against small sample repositories.
- Usage-limit and auth errors are detected by matching CLI error text.
- The automated developer may only run allow-listed git commands and your test command.
- The local API has no authentication beyond loopback, header and origin checks.
- Worktrees and branches are not cleaned up automatically.
- Vendor terms leave open questions about third-party tools automating personal subscriptions (see docs/PROVIDERS.md).
